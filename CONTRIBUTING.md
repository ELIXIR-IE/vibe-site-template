# Contributing

Thank you for helping improve the VIBE site template.

This repository is the **template** that each edition copies. Content for a
specific edition belongs in that edition's own repository, not here.

## Suggest a change

Open an issue describing what you would like changed and why. For a bug,
include the page, what you expected and what happened.

## Make a change

1. Fork the repository and create a branch.
2. Run `npm install`, then `npm run dev` to preview.
3. Keep changes general: they should help every future edition.
4. Run `npm run build` and `npm run check` before opening a pull request.
   The same checks run automatically on every pull request.
5. If you change brand colours, change them in both `src/styles/tokens.css`
   and `scripts/build-logo.mjs`.
